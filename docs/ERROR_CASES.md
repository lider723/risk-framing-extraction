# 典型错误：

下面的中文是整理者概述，不冒充新闻原话或模型原始输出。实际候选ID、最小模型判定片段、单元映射及原记录hash在 [case_index.json](../examples/case_index.json)。全文和逐字证据留在受限原实验包；这里不发布新闻全文。

这些是已暴露开发案例，不是独立测试。参考判断来自原人工单元与同一助手的LLM辅助复核，研究口径争议另外标出，没有据此改Gold。

## 1. 把“不同人的观点”混成一人的观点

**3175258011，P022，v5 C05。** 文章先转述一些人担心AI威胁人类创造力，随后介绍导演把AI视作创作素材的不同看法。导演不担心，不等于前一项担忧没有出现。

R2_V5、E、S、B都拒绝这个候选，输出0单元。V5首轮实际判定把主张改成导演不认为AI是威胁，再据此拒绝。同输入有限重复中，V5和B均确认0/3。

**要排查：** 归属是否被重写；是否额外要求创造力之外再出现下一层损失。**待裁决：** “威胁创造力”是否足够具体仍可由研究者讨论；原参考纳入，评分不偷偷删除它。不能仅用归属错误掩盖具体性边界。

## 2. 把已经发生的滥用当作“只是用途”，或合成一条

**2881368889，P017，C02。** 文章列出ChatGPT被用于抄袭论文、低质科幻投稿和内容农场假新闻。原参考分别纳入抄袭、假新闻；低质投稿不自动增加为第三项风险。

V5、B确认C02，却都只映射到一个U01；E、S直接拒绝。E的实际理由是这些只是用途，没连接到具体损害。同输入重复中V5和B均确认2/3，但正确拆开两类后果均为0/3。

**要排查：** 为何明确滥用仍被要求额外证明损失；候选是否被当成不可拆的一整块。整项消失是漏提，不是修好了混合。

## 3. 同一句的两项独立风险拆不开

**2891648776，P008，C03。** 同句说岗位被自动化消除，以及自主战争超出人类控制。原Gold本来就有两个单元，不是为了救分新增。

V5、E、S、B均把C03组织成一个复合单元；两阶段S的第一阶段也未先拆开。P006的泛泛危险／安全关切还会被独立建项。

**要排查：** 一候选能否形成多个独立命题；第二阶段能否识别上一步未拆开的主张，而不是结构合法就继续归并。内容可能覆盖两项，严格最多算一个TP，异质合并另报。

## 4. 同一风险的概括、实例和应对并不拢

**3175482871，C01–C11。** P007、P009、P014–P020及P027多处讨论广告主对AI广告投放、展示和定位的控制不足；P033是回应／建议。P018品牌素材出现在另一品牌广告中，则是原参考另列的风险，不能一起删掉。

V5输出9条，其中同一控制风险有7条额外重复。E缩到1条，但同时丢掉独立品牌素材风险；S、B各输出10条，还把治理语境独立建项。B另加原文未明确的“未经同意”限定。

**要排查：** 减少重复是否同时删掉有效风险；如何把治理建议连回同一风险而不当作新风险。不能把“条目少了”当成正确归并。

## 5. 原参考自身有层级重叠，不能全部怪模型

**3313656160。** C02–C06对应P007–P013的认知／学生技能问题；C09–C11对应P025–P027的观点偏移；C13在P030说未来工作受威胁。原参考把认知概括与学生技能分别列项，存在粒度重叠。

V5输出4条，S输出9条。S补回部分原来漏掉的内容，也把认知、观点偏移重复组织；P028的泛泛风险忽视评价仍被独立计数。E／B条目更少，也未解决全部漏提。

**要排查：** 同风险的概括和具体表现怎么对应。**待裁决：** 认知／学生技能是否合并。当前保留原5条参考；评分另用别名关系审计重复，不改分母来提高成绩。

## 6. 同段出现AI和裁员，不等于AI导致裁员

**3182933225，P002/C01、P007/C02、P013/C03。** 文章讲AI精简政府、找浪费、筛查合同中的DEI条款；另讲裁减岗位，没有明确说裁员由AI造成。原参考为无风险。

V5输出3条，包括中性计划、AI致裁员的无依据因果、DEI筛查边界项。E、B输出0条；S保留1条DEI边界项。第一轮D3也出现把这些计划写成风险的问题。

**要排查：** 是否用常识补了AI—损害链。**待裁决：** DEI筛查是否在本文构成明确负面后果；不能直接当成已经证实的歧视，也不能和无依据的AI裁员混为一谈。

## 两个补充回归例（需要时看）

**3297946987：发现漏了，确认阶段不能宣称修好了。** v5只有P004/C01、P007/C02、P014/C03、P016/C04；实际股价损失链在P009/P011，未进入候选。B新增把盈利担忧写成股价下跌原因的单元，也不等于恢复了原来的、有条件和混合因素的损失关系。须分清发现遗漏、确认遗漏与因果改写。

**3367280940：新流程不能把原来正确的文章改坏。** P006/C01明确关联AI、行业整合与影视预算／新人机会威胁；P023/C02只是对人类作曲细腻能力的赞赏。V5、E各输出1条；S、B各2条，把能力比较加成独立风险。新增项暂按边界项，不自动推成实际创作损害。
